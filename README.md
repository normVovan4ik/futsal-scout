# ⚽ Futsal Scout & Hub (5x5)

Аналитический хаб и генератор карточек игроков (в стиле FUT / EA FC) специально для **любительского футзала (5х5)**.

## 🚀 Особенности
1. **Футзальные амплуа:**
   - 🎯 **Столп (Пивот)** — наконечник атак, игра у чужих ворот.
   - ⚡ **Бровка / Универсал (Ала)** — мобильный край, разгон атак, дриблинг и пасы на дальнюю.
   - 🛡️ **Защитник (Фиксо)** — чистильщик, первый пас, надежность в обороне.
   - 🧤 **Вратарь (Голкипер)** — спасения и игра ногами в качестве пятого полевого.

2. **Честный расчет характеристик из реальных протоколов любительских лиг:**
   - **FIN (Киллер / Финишинг):** голы в среднем за матч, хет-трики.
   - **VIS (Видение / Плеймейкинг):** ассисты, передачи под удар.
   - **IMP (Импакт / Влияние):** средний набор очков (Гол+Пас) за матч.
   - **DISC (Дисциплина / Агрессия):** учет ЖК, КК и фолов (от 99 у Джентльменов до 35 у Костоломов).
   - **ATT (Явка / Посещаемость):** % сыгранных матчей — главный скилл любительского футбола!
   - **CLUTCH (Решала):** победные голы и статус MVP матчей.

3. **Юморные и реальные бейджи любительского футзала:**
   - ⏰ *«Будильник в 9:00»* — 100% явка даже на ранние матчи.
   - 🟨 *«Абонемент на горчичник»* — регулярные желтые за разговоры и срыв атак.
   - 🎯 *«Замыкатель дальней»* — львиная доля голов с метра в пустые ворота.
   - 🧙‍♂️ *«Бразильский альтруист»* — ассистов больше, чем забитых мячей.
   - 👕 *«Пятый полевой»* — умение подключиться в манишке.
   - 👑 *«Тащит весь район»* — более 50% голов команды на его счету.

4. **Head-to-Head дуэли (Сравнение):**
   - Сравнение двух игроков лицом к лицу.
   - Сравнение команд перед игрой (атака vs оборона, прогноз).

5. **Экспорт:**
   - Скачивание карточки игрока в формате PNG для командного чата.
